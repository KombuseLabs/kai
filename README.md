# kai - kombuse auto improve

## What works today

```sh
cargo run                           # prints: hello kai
cargo run -- --help                 # the options
cargo run -- --log-level debug      # log lines on standard error
```

kai needs Rust; `rust-toolchain.toml` names the version.
