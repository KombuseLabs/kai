# Security

kai is at its beginning: today it runs no agent and handles no key. The
README says what works.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately
through GitHub: on this repository's **Security** tab, choose **Report a
vulnerability**. Describe what you did, what happened, and the commit you
used; a command that reproduces it helps most. Never include a real key: a
report needs the key's name, not its value.

Fixes land on `main`; there are no maintained release branches.
